## 可判断验收标准

1. 普通批次评测完成且主因/次因知识缺失才生成；合格/非缺失/资料冲突含违规组合/未完成/取消/效果验证均不生成，独立触发规则测试全部通过。
2. 每缺失点一草稿，不同回复相同缺失点仍各自保留；仅生成标准问，答案为空，原问题单存，完整回复上下文/来源及已保存片段reason直接复用。
3. QA调用/解析/字段缺失最多3次成功即停；空参考答案为正常草稿，不当失败。耗尽单列生成失败不可审核，评测及证据调用数不增加、不回滚成功评测；全部QA终态才释放009窗口。
4. 来源/片段定位/≤50码点/答案为空等确定性检查全部通过；正式质量按021固定全部应生成集合，标准问和reason均符合才计合格，≥ceil(应生成总数×90%)，漏生成/失败计不合格，用户语义判断留022。
5. 按006和实际技术环境运行该模块适用单测、必要集成/冒烟及契约检查，留真实命令/结果；mock仅用于故障或确定性隔离，不作为真实模型语义通过证据。已有规则全部沿用原标准；需要用户判断的内容有明确确认人和记录。未定条件不能宣称满足。
