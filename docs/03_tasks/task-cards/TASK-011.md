## 可判断验收标准

1. 三维1～5整数、沿用共用档位/每理由≤50码点；综合均值两位、任一维<4即Badcase；5/5/3＝4.33且Badcase、4/4/4合格。主因五类唯一，次因前四类多选排除主因、可空。
2. 两资料均无答案才知识缺失：纯兜底准确性3、含编造1；已有答案兜底准确性1/主因敷衍；违规承诺准确性1/合规主因并保留缺失次因。冲突准确性1，单纯主因其他/证据不足，同时违规承诺合规主因，两者均标识禁止QA。
3. 每缺失点产生来源可定位片段及reason并持久化，不完整由010处理；QA后续直接复用，不在013重做证据。原上下文仅追加待评回复，保留规则/库/Prompt/模型版本追溯。
