## 可判断验收标准

1. 通过率＝合格数/成功数；平均分＝成功case三维总分/(成功数×3)；异常率＝最终异常case数/总数。100条90成功84合格总分1080时平均4、异常10%、双预警且不通过。
2. 批次仅异常率≤5%且无Badcase通过；通过率<95%和异常率>5%分别预警；恰95%/5%不触发对应预警，预警与批次结论分开。
3. 零成功显示通过率/平均分无数据、异常100%及预警/不通过，不生成QA；重试不增case计数、取消批次不汇总有效指标。
4. 全部case终态后汇总，百分比及平均分显示两位但阈值按未舍入值；输出带批次/问题集合以供018准确跳转，边界/零分母/舍入测试全部通过。
5. 按006和实际技术环境运行该模块适用单测、必要集成/冒烟及契约检查，留真实命令/结果；mock仅用于故障或确定性隔离，不作为真实模型语义通过证据。已有规则全部沿用原标准；需要用户判断的内容有明确确认人和记录。未定条件不能宣称满足。
